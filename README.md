## 서비스 소개
**HomeAid**는 생활 서비스 매칭 플랫폼으로. 고객(수요자)과 매니저(공급자)를 연결하여 청소, 세탁, 가사 등 다양한 서비스를 쉽고 빠르게 예약할 수 있도록 하며 다음과 같은 문제를 해결하고자 합니다.
- 고객이 직접 검증된 매니저를 손쉽게 예약할 수 있도록 지원
- 매니저가 자신에게 맞는 일정과 지역에서 유연하게 일할 수 있도록 환경 제공
- 관리자에게는 매칭, 결제, 정산을 효율적으로 관리할 수 있는 백오피스 제공

## 기능 소개
**수요자**
   - 서비스 예약
     - 서비스 시간/옵션 선택, 위치 입력
     - 매칭된 매니저에 대한 최종 확인
   - 리뷰
     - 서비스 완료 후 매니저에 대한 리뷰 작성
   - 마이페이지
     -  내 정보 수정
      - 주소 관리
      - 작성한 리뷰 보기
      - 관리자와 1:1 문의
      - 결제 확인하기
        
**매니저**
   - 프로필
     - 활동 지역, 시간, 요일, 경력 등록
     - 사진, 매니저 검증 서류 등록
   - 매칭
     - 매칭 상태별 리스트 확인
     - 매칭 수락 /거절(사유입력)
   - 서비스 작업
     - 예약 건 서비스 장소 체크인 / 체크아웃
   - 리뷰
     - 서비스 완료 후 고객에 대한 리뷰 작성
     - 받은 리뷰, 평점 확인
   - 관리자 상담
     - 게시글 등록, 답변, 삭제
     - 비공개글
     - 상태 필터링
   - 정산
     - 월별 완료 건수, 지급액, 정산일 확인
       
**관리자**
- 대시보드
    - 오늘 매출, 총 매출, 환불 금액등 그래프로 한눈에 확인
- 수요자 & 매니저 조회
    - 수요자 상세조회 및 리스트 관리
    - 매니저 서류 제출 및 매니저 활동 상태 관리
- 수요자 결제 & 매니저 정산
    - 수요자 결제내역 상세조회 및 환불 요청 관리 포함
    - 매니저 주 단위 정산 및 지급 관리
- 매칭 알고리즘
    - 지역, 시간대, 평점, 거리 등 고려하여 매칭
- 리뷰 관리
    - 수요자 및 매니저가 작성한 리뷰 관리
- 통계
    - 전체, 회원, 정산, 예약, 매칭 모니터링 (일/주/월 단위)
- 문의글 관리
    - 수요자/매니저 문의글 조회
    - 문의글 답변 작성
